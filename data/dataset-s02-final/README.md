# Dataset consolidado da Sprint 2

300 repositórios, janela UTC 2025-01-01 a 2025-12-31. A coleta e os cálculos B/C estão completos. A coluna cfr_b é exploratória: a rotulação independente e o consenso da nova amostra-ouro ainda são necessários para validar o F1.

CFR é proporção entre 0 e 1. Tempos são horas salvo campos explicitamente _days. Frequência é releases por semana. Vazios não são zeros. Valores de recuperação censurados estão separados das medianas observadas.

Dados e cache permanecem nas pastas data/jobs. O pacote pequeno contém métricas e referências para rotulação; os inputs CSV e arquivos brutos volumosos permanecem locais. Veja docs/DATA-DICTIONARY.md e docs/PARTE-C-S02.md no projeto.
